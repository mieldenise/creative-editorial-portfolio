## Creative Editorial Developer Portfolio

## Project Description

The Creative Editorial Developer Portfolio is a responsive personal portfolio website designed to showcase my skills, projects, and experience as a Computer Science student.

The website was created using HTML, CSS, JavaScript, and Figma. It follows a creative editorial design style with a focus on typography, visual hierarchy, responsive layouts, and user-friendly navigation.

## Featured Project

### Emilia's Place

Emilia's Place is a private resort and events venue website project designed to present the resort's facilities, gallery, and contact information through a responsive website.

## Design Concept

The portfolio uses a creative editorial design style inspired by modern magazine layouts. It uses Playfair Display for headings, Inter for body text, and JetBrains Mono for selected labels and interface elements.
