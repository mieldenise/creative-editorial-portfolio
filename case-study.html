Here are some of the projects I've worked on, showcasing my skills in web development and design. Each project reflects my growth, creativity, and dedication to building meaningful digital solutions.

Project Overview

A responsive website concept for a family-owned private resort and events venue in Sapalibutad, Angeles City.

My Role
UI/UX Design & Frontend Development
Tools Used
HTML, CSS
Duration
2 weeks (concept design)
Project Goal
Present the venue, facilities, and event possibilities through a clear and welcoming digital experience.

The Process

01
Problem

The project aimed to address the lack of an online presence for a private resort, requiring a modern and inviting digital platform to showcase its amenities and event spaces.

02
Research & Planning

Researched user expectations for resort booking websites and mapped out a simple, intuitive site navigation structure.

03
Design & Development

Structured and styled the resort website from scratch using HTML5 and CSS3 layout techniques.

04
Testing & Refinement

Verified mobile responsiveness, adjusted element spacing, and ensured smooth rendering across major web browsers.

The Solution

A clean, modern, and responsive website featuring key venue details, event options, and clear contact links with appealing visuals.

The Result

The project successfully presents the resort's features, making it easier for potential guests to explore.

Key Takeaways
Clear content layout • Responsive design importance • Visual branding consistency
